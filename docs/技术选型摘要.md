# ADVP 技术选型摘要（公开版）

| 项目 | 内容 |
|---|---|
| 版本 | v0.8.238 |
| 日期 | 2026-10-26 |
| 面向 | 用户、评审人员、贡献者 |

## 1. 总体架构

ADVP 是 Windows 本地应用：React + TypeScript 前端、FastAPI 后端、SQLite 持久化；AI 选型通过 Provider 适配层接入，科学计算使用 Python 生态，3D 采用浏览器 + 服务端双后端。

## 2. 数据与分析

| 层 | 选型 | 说明 |
|---|---|---|
| 表格 | Polars / pandas | CSV/JSON/Parquet/Excel，采样画像 |
| 科学数组 | h5py、xarray、astropy | HDF5/NetCDF/FITS |
| 影像 | nibabel、pydicom | NIfTI、DICOM、RAW |
| SQL | SQLAlchemy + 驱动 | SQLite/PostgreSQL/MySQL，只读查询 |
| 流 | websockets、confluent-kafka | WebSocket/Kafka 有界窗口与实时会话 |

## 3. AI 与图表

- Provider：OpenAI 兼容与 Anthropic 兼容接口；密钥存 Windows 凭据管理器。
- 选型：规则候选 → 结构化输出 → 七维评分 → Top3；失败/预算超限时降级为规则 Top1。
- 2D：Plotly；地图：deck.gl；网络：Cytoscape.js；桑基/旭日/实时：ECharts；影像：VTK.js。
- 3D：Scene JSON v1；浏览器 VTK.js；服务端 VTK/Mayavi 离屏；trame SciView。

## 4. 3D 与大数据

- 服务端渲染在独立 Python 环境运行，通过 `ADVP_RENDER_PYTHON` 指定。
- 大体积数据按步长采样与 LOD；浏览器体渲染限制内联体素数量。
- 动画支持相机路径、断点续渲与 MP4/GIF。
- 无 GPU 时探测软件渲染并降级。

## 5. 报告、安全与打包

- 报告：Markdown/HTML/PDF；HTML 由受控 Markdown 渲染，PDF 使用 Playwright + Edge。
- 安全：仅回环监听、Host/Origin 校验、可选会话令牌、CSP；生成代码在受限子进程沙箱中验证。
- 日志：JSON Lines、14 天滚动、密钥与绝对路径脱敏。
- 打包：conda-pack + Inno Setup；前端静态文件由后端托管。
