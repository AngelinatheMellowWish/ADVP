## 1. 信息架构

```text
ADVP
├── P01 工程首页
│   ├── 新建工程 → P02
│   └── 打开工程 → P04 / P05 / P06
├── P02 数据导入
│   ├── 文件 / 数据库 / URL / 文档 / 实时流

├── P04 AI 管线运行

├── P07 报告与导出
├── P08 Provider 设置
├── P09 追溯与审计

```

**全局导航：** 左侧固定导航（首页、数据、分析、图表、报告、追溯、设置）；顶部为工程上下文、保存状态、语言切换、帮助。主工作区最大宽度不设限，最小支持 1280×800。

## 2. 全局组件与状态

| 组件 | 说明 |
|---|---|
| 顶部栏 | 工程名、数据版本、保存状态、语言切换、帮助、账户（无登录，仅本地标识） |
| 左侧导航 | 图标 + 文案；当前项高亮；折叠模式仅图标 |
| 任务条 | 底部或顶部浮层，展示后台任务数量、进度、取消入口 |
| Toast | 成功/警告/错误；错误提供“查看详情”和“复制诊断” |
| 模态框 | 二次确认、Top3 选择、连接测试结果、许可声明 |
| 空状态 | 插画/图标 + 一句解释 + 主行动按钮 + 示例数据入口 |
| 加载态 | 骨架屏用于列表；进度条用于任务；不确定进度用阶段文案 |
| 错误态 | 原因、影响、建议动作、诊断 ID；不暴露堆栈给普通用户 |

**快捷键（建议）：** `Ctrl+N` 新建工程，`Ctrl+S` 保存，`Ctrl+K` 命令面板，`Ctrl+Enter` 运行分析，`Esc` 关闭模态框。

## 3. 页面详细说明

### P01 工程首页

**目标：** 快速进入工作，展示最近工程与系统健康状态。

**布局：**

- 顶部：产品名 ADVP、搜索框、语言切换、帮助。
- 主区：欢迎语 + “新建工程”主按钮；最近工程卡片网格（缩略图、名称、数据源类型、更新时间、状态标签）。
- 右侧栏：系统状态（本地服务、AI Provider、GPU、磁盘）、最近任务、示例工程入口。
- 底部：版本号、许可、文档链接。

**关键交互：**

- 点击工程卡片 → 打开工程并进入上次所在页面。
- 搜索按名称/标签/数据源过滤；无结果时提供“新建”。
- 新建工程 → 弹出向导（名称、位置、模板）→ 进入 P02。
- 系统状态异常（Provider 未配置、GPU 不可用）显示可点击的修复入口。

**状态：** 空（首次使用，展示引导与示例）、加载（骨架卡片）、错误（工作区不可写，给出路径与权限建议）。

---

### P02 数据导入

**目标：** 用最少步骤接入六类数据源，并在导入前发现问题。

**布局：**

- 顶部步骤条：导入 → 预览 → 分析。
- 左侧：数据源类型标签页（文件、数据库、远程 URL、文档、实时流）。
- 中部：拖拽上传区 / 连接表单 / URL 输入 / 文档上传 / 流地址。
- 右侧：导入设置（编码、分隔符、表头、工作表、字段类型、采样行数）。
- 底部：数据预览表（前 20 行）、字段类型标记、行数估算；主按钮“确认导入”。

**关键交互：**

- 拖拽文件后自动识别类型；识别失败允许手动选择。
- 数据库连接：测试连接 → 浏览库表 → 选择表/视图或输入 SQL → 预览。
- 远程 URL：输入 URL，支持 Header/认证；显示响应状态与大小。
- 文档：上传 PDF/Word → 展示候选表格缩略图与置信度 → 选择。
- 实时流：输入 WebSocket/Kafka 地址 → 试连 5 秒 → 展示样例消息 → 确认字段映射。
- 大文件：显示“将使用分块/采样”的提示与预计内存。
- 导入失败：保留用户输入；提供“查看日志”“复制诊断”。

**状态：** 空（拖拽区）、解析中（进度）、部分成功（多文件时逐项状态）、失败（原因与替代方案）。

---

### P03 数据预览与质量

**目标：** 让用户在分析前理解数据质量与风险。

**布局：**

- 顶部：数据集名、行数/列数、大小、来源、采样标记；主按钮“开始 AI 分析”。
- 左侧：字段列表（名称、类型图标、缺失率、唯一值）；支持搜索与类型筛选。
- 中部：数据表格（分页、列宽调整、固定列）；点击列头查看统计。
- 右侧：质量评分卡、问题列表（阻断/警告/提示）、敏感字段、修复建议。
- 底部：分布/相关性缩略图；点击展开大图。
- 分析摘要：相关性、数值分布/偏度、时间跨度/断档与地理范围；可手动重新计算。
- 数据清洗：缺失/异常/去重/类型/重命名/删列；生成派生数据集、变更日志，支持撤销上一步与回滚原数据。

**关键交互：**

- 点击质量问题 → 定位到相关字段/行；提供“应用建议”“忽略”“查看影响”。
- 敏感字段开关：默认脱敏；可逐列配置。
- 字段类型可手动覆盖；覆盖后重新计算统计。
- “开始 AI 分析”前展示将发送给模型的上下文摘要（字段、样本行数、脱敏项）。

**状态：** 无质量问题（绿色通过）、有警告（黄色）、有阻断（红色，禁止继续或需确认）。

---

### P04 AI 管线运行

**目标：** 展示自动化过程，允许暂停、取消、重试与对话修正。

**布局：**

- 顶部：任务标题、数据源、开始时间、预计成本、状态标签。
- 中部：阶段步骤条（提取 → 画像 → 清洗 → 分析 → 选图 → 渲染 → 报告），每步显示状态、耗时、摘要。
- 左侧：实时日志/事件流（可折叠），按级别筛选。
- 右侧：当前步骤详情（模型、Token、费用、降级事件、人工介入点）。
- 底部：对话输入框（“换一种图”“不要删除异常值”“改用对数轴”）；暂停/取消/重试按钮。

**关键交互：**

- 点击阶段 → 查看该步输入/输出摘要与生成代码。
- 低置信度选图 → 右侧弹出 Top3 卡片（图表缩略图、理由、评分），默认高亮最高分；全自动模式下自动继续。
- Provider 失败 → 时间线插入“降级事件”，说明切换原因。
- 预算达到上限 → 暂停并提示调整预算或改用低成本模型。
- 完成后 → “查看结果”进入 P05/P06，“查看报告”进入 P07。

**状态：** 运行中、暂停、成功、部分成功（有降级）、失败（可重试）、已取消。

---

### P05 2D 图表工作台

**目标：** 查看、调整、比较与导出 2D 图表。

**布局：**

- 左侧：字段面板（维度、度量、分组），拖拽到编码槽。
- 中部：图表画布；顶部工具栏（图表类型、撤销/重做、重置、导出）；底部数据表切换。
- 右侧：配置面板（坐标轴、聚合、排序、配色、图例、标注、交互）；选型评分卡（各维度分数、理由、备选）。
- 顶部：图表标签页（多图切换）；“候选 Top3”按钮。

**关键交互：**

- 修改字段映射/聚合 → 图表即时更新；配置写入工程。
- 点击“为什么选这个图” → 展开选型理由与评分明细。
- 低置信度时显示 Top3 对比条；可一键切换并记录原因。
- 导出：PNG/SVG/PDF、独立 HTML、代码；导出前预览尺寸与字体。
- 对话入口：自然语言修改图表，展示变更 diff。

**状态：** 无图（引导选择）、渲染中（骨架）、渲染失败（原因与重试）、数据为空（提示过滤条件）。

---

### P06 3D 科学视图

**目标：** 提供科研级 3D 交互与体渲染控制。

**布局：**

- 左侧：数据/字段、几何类型、后端选择（自动/WebGL/Mayavi/trame）、LOD 与降采样设置。
- 中部：3D 画布（全屏优先）；右上角相机预设、重置、截图；底部时间轴（动画）。
- 右侧：传输函数编辑器（曲线/色标）、裁剪平面、光照、标注、色标范围。
- 顶部：场景状态（后端、GPU、帧率、数据规模、降采样标记）。

**关键交互：**

- 旋转/缩放/平移；点击探针显示字段值。
- 传输函数拖拽即时预览；重计算时显示进度。
- 切换后端：提示可能的重渲染时间与差异；保留相机。
- 动画：播放/暂停、帧率、导出 MP4/GIF。
- 无 GPU/内存不足：顶部警告条 + 一键降级/降采样。
- 保存 Scene JSON；导出脚本。

**状态：** WebGL 就绪、服务端渲染中、降级模式、失败（驱动/显存/数据格式）。

---

### P07 报告与导出

**目标：** 组织分析结果为可交付报告，并管理导出任务。

**布局：**

- 左侧：报告大纲（摘要、数据质量、图表、结论、局限、附录），可拖拽排序。
- 中部：报告预览（Markdown 渲染，接近 PDF 版式）。
- 右侧：导出设置（格式、语言、模板、分辨率、是否含代码/追溯）、导出队列。
- 底部：manifest 预览（数据哈希、模型、提示词版本、代码版本）。

**关键交互：**

- 勾选图表加入报告；自动生成文字结论，可编辑。
- 切换中英文模板；图表标题与正文语言联动。
- 导出任务后台执行；完成后打开文件夹/下载。
- 导出前敏感信息检查（路径、样本、密钥）。
- 生成“可复现包”（脚本 + manifest + 依赖锁）。

**状态：** 无内容（引导添加图表）、导出中、成功、失败（磁盘/权限/字体）。

---

### P08 Provider 设置

**目标：** 配置 OpenAI/Anthropic 兼容服务、主备顺序与数据外发策略。

**布局：**

- 左侧：Provider 列表（名称、类型、模型、状态、主/备标签）；“添加 Provider”。
- 中部：配置表单（名称、协议、Base URL、API Key、模型、超时、重试、代理、自定义 Header）。
- 右侧：连接测试结果、能力探测（流式/JSON/工具）、成本价格表、数据外发策略。
- 底部：主备顺序拖拽；全局预算设置。

**关键交互：**

- API Key 输入后仅显示掩码；保存写入 Windows 凭据管理器。
- “测试连接”显示延迟、模型列表（若支持）、错误分类。
- 切换“发送全量数据”需二次确认，并展示将发送的内容预览。
- 删除 Provider 同步删除凭据；若有任务引用，提示替换。
- 价格表可编辑；显示估算示例。

**状态：** 未配置（引导）、测试中、成功、失败（认证/网络/协议不兼容）、已禁用。

---

### P09 追溯与审计

**目标：** 回答“这个结果怎么来的、花了多少、能否复现”。

**布局：**

- 顶部：任务选择器、时间范围、导出追溯。
- 左侧：DAG 视图（节点可点击）；节点颜色表示状态。
- 中部：步骤详情（输入/输出摘要、参数、模型、提示词版本、Token、费用、耗时）。
- 右侧：代码查看器（生成/修改的代码、diff）、数据血缘、日志。
- 底部：成本时间线（按步骤/模型/日期）。

**关键交互：**

- 点击节点 → 右侧联动；可“从此步重跑”。
- 代码 diff：高亮变更；复制/下载。
- 血缘：点击数据集查看来源与派生链。
- 日志筛选（级别、步骤、Provider）；复制诊断。
- 导出追溯 JSON/Markdown。

**状态：** 无任务、加载、成功、失败节点高亮、外部依赖缺失。

---

### P10 设置与关于

**目标：** 管理应用级设置、诊断与版本信息。

**布局：**

- 分区：通用（语言）、工作区（路径、磁盘占用、清理）、分析（采样、重选次数、并发）、安全（沙箱限额、日志脱敏）、AI（默认 Provider、预算）、关于（版本、许可、更新、文档）。
- 右侧：当前值摘要与“恢复默认”。

**关键交互：**

- 语言切换即时生效。
- 清理临时文件前显示占用与影响；二次确认。
- 沙箱限额修改需重启任务队列。
- 查看 `THIRD_PARTY_NOTICES` 与开源许可。
- 检查更新（可选，不默认联网）。

**状态：** 默认、已修改未保存、保存成功、保存失败（权限/磁盘）。

## 4. 视觉设计令牌（建议）

### 4.1 色彩

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg-base` | `#0B1220` | 应用背景 |
| `--bg-panel` | `#111A2C` | 面板/卡片 |
| `--bg-elevated` | `#16223A` | 浮层/模态框 |
| `--border-subtle` | `#22304A` | 分隔线/边框 |
| `--text-primary` | `#E6EDF7` | 主文本 |
| `--text-secondary` | `#9FB0C8` | 次要文本 |
| `--accent-cyan` | `#35D0BA` | 主强调/成功 |
| `--accent-violet` | `#8B7CFF` | 次强调/3D |
| `--warning` | `#F2B84B` | 警告 |
| `--danger` | `#FF6B6B` | 错误/危险 |
| `--info` | `#5AA9FF` | 信息 |

数据色板：`#35D0BA, #5AA9FF, #8B7CFF, #F2B84B, #FF8FA3, #7ADB8A, #C9A7FF, #6FD3E7`（色盲友好需用工具校验）。

### 4.2 字体与排版

- 中文：`"Microsoft YaHei UI", "PingFang SC", "Noto Sans SC", sans-serif`。
- 英文/数字：`Inter, "Segoe UI", system-ui, sans-serif`。
- 等宽：`"Cascadia Code", "JetBrains Mono", Consolas, monospace`。
- 字号：12/13/14/16/20/24/32；正文 14px，行高 1.6；标题 600 字重。

### 4.3 间距与圆角

- 间距：4/8/12/16/24/32/48。
- 圆角：6px（控件）、10px（卡片）、14px（模态框）。
- 阴影：低对比、深色环境使用边框与微光而非重阴影。

## 5. 原型说明

- 文件：`docs/prototype/index.html`，单文件、无外部依赖、离线可用。
- 使用左侧导航或顶部页面索引切换 10 个页面。
- 原型包含静态示例数据与可视化示意；按钮用于演示状态切换（如 Top3 模态框、导出队列、Provider 测试）。
- 原型不代表最终视觉细节；实现时以设计令牌与可访问性要求为准。
- 原型中的 3D 为 CSS/SVG 示意，不包含真实 WebGL/VTK 渲染。
